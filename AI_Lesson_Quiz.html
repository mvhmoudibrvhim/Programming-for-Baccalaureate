Applied Understanding

Answers 19–35

19.

Machine learning takes in examples of data and learns the patterns within it, then uses those learned patterns to make predictions or judgments about new, unseen data — rather than following only fixed, hand-written rules.

20.

Deep learning is a more advanced, specialized form of machine learning that specifically uses neural networks (modeled on the brain's neurons) to learn more complex patterns, typically requiring large-scale data — whereas basic machine learning can use simpler methods on smaller data.

21.

Generative AI is built on top of deep learning: it uses deep learning's neural network techniques, but instead of just making a prediction or judgment, it generates brand-new data (text, images, audio) that didn't exist before.

22.

Sample answer: (1) Spam sorting — learns from examples, because spam patterns vary and change over time; (2) Video recommendations — learns from examples, because it's based on personal viewing history; (3) Translation — learns from examples, because language has too many exceptions for fixed rules alone.

23.

Both work by learning patterns from data (spam patterns in emails, purchase patterns in customer history) to make a prediction or judgment — sorting an email as spam/not spam, or predicting what a customer might buy — even though the tasks themselves look different.

24.

It would need to learn from a large set of labeled photographs of both healthy and diseased crops, using deep learning/image analysis, so it can learn the visual patterns that distinguish the two.

25.

Its judgment might be wrong if it encounters a disease pattern, lighting condition, or crop type it has rarely or never seen in its training data.

26.

Deep learning needs large amounts of data to reliably learn a pattern; if a certain case is rare in the training data, the system hasn't had enough examples to learn it well, so it is more likely to make mistakes on it.

27.

Older, rule-based programs follow fixed, hand-written instructions that a programmer defines in advance. AI that learns from data instead studies many examples and works out its own patterns/rules, which lets it handle situations the programmer never explicitly coded for.

28.

Generative AI relies on the neural network techniques developed in deep learning to understand and generate data — it doesn't exist independently of deep learning, but extends it toward creating new content, so it sits nested inside deep learning rather than beside it.

29.

Generative AI example: ChatGPT writing a new paragraph of text. Machine learning (not generative) example: a spam filter sorting emails — it classifies/predicts, it does not generate new content.

30.

"Nested categories" means each technology sits inside the next broader one, like Russian nesting dolls: machine learning is a type of AI, deep learning is a type of machine learning, and generative AI is a type of deep learning — they are not four separate, equal, parallel fields.

31.

Open-ended reflection — answers will vary. A strong answer names the learner's prior belief and explains specifically what changed (e.g., "I thought AI was one thing, but now I see it's four nested levels of specialization").

Generative AI can produce a finished-looking answer almost instantly, which saves time (speed = benefit). But because it generates the most statistically likely-sounding text rather than verified facts, it can produce confident answers that are simply wrong (accuracy = risk).

Advanced Analysis

Answers 36–50

36.

Model answer: AI is the broadest field, covering any technology that reproduces intelligent human behavior (e.g., a translation app). Machine learning sits inside AI, learning patterns from data (e.g., a spam filter). Deep learning sits inside machine learning, using neural networks for complex patterns (e.g., pedestrian recognition in self-driving cars). Generative AI sits inside deep learning, using it to generate new data (e.g., ChatGPT writing text). Each is nested inside the one before it, from broadest to most specialized.

37.

A hallucinated answer looks correct and confident but may contain false facts, invented sources, or wrong figures. Using it as-is in a report could spread misinformation and damage credibility. Instead, learners should treat AI output as a first draft and verify any factual claims against a trustworthy source before including them.

38.

Open investigation task — answers will vary by student. A strong answer names a specific, sourced example (a news article, official report, or the student's own tested prompt with a screenshot) rather than a vague or remembered claim.

39.

Sample answer: Benefit for the student — saves time researching and drafting; benefit for the teacher — none directly, though it can free time for feedback on ideas rather than wording. Risk for the student — may submit false information without realizing it; risk for the teacher — harder to assess a student's true understanding.

40.

Sample answer: Allow generative AI for homework only as a research/drafting aid, with a rule that any facts or citations must be independently verified before submission. Reasons: (1) it teaches responsible use of a tool students will encounter throughout life; (2) it balances the speed benefit against the accuracy risk rather than ignoring either one.

41.

Both learn patterns from data rather than following fixed rules. The difference: deep learning is a specialized subset of machine learning that uses neural networks (modeled on brain neurons) and typically needs much larger-scale data to learn more complex patterns, such as recognizing objects in images, which simpler machine learning methods struggle to do well.

42.

The claim confuses one specific product (ChatGPT, a generative AI application) with the entire field of AI. Using nested categories, ChatGPT is an example of generative AI, which is only the most specialized layer built on deep learning, which itself is a subset of machine learning, which itself is a subset of AI. So ChatGPT is one small part of AI, not AI itself.

43.

Both use data, but they perform different jobs: recommending a product uses learned patterns to make a prediction/judgment about which existing item a user might want — this is machine learning. Generating a brand-new image from a prompt creates entirely new content that did not exist before — this is generative AI, built on deep learning specifically for content creation.

44.
